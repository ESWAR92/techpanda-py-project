# 🐍 Web Server Log Analyzer

## 📌 Project Overview
The **Web Server Log Analyzer** is a Python project that analyzes web server log files to identify frequently accessed IP addresses and common HTTP status codes. It helps summarize server activity and understand basic traffic patterns.

## 🎯 Project Objectives
- Identify the most frequent IP addresses.
- Find the most common HTTP status codes.
- Analyze log file data using Python.
- Visualize HTTP status codes using a pie chart.

## ✨ Features
- Read and process web server log files.
- Extract IP addresses from log entries.
- Count IP address frequencies.
- Analyze HTTP status codes.
- Display results using charts.
- Export analysis results to CSV files.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- CSV
- Regular Expressions

- `log_analyzer.py` — Main Python program.

## ⚙️ Requirements
Install the required Python libraries:

```bash
pip install pandas matplotlib
```

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure your log file is available at the path specified in the Python program.
4. Install the required libraries.
5. Run the Python script:

```bash
python log_analyzer.py
```
